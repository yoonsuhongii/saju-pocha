# 🏮 사주포차 거리 2030 — 월드모델 파일럿

**혜화역 2번 출구, 대학로 마로니에공원 앞**에 늘어선 한국식 포장마차 거리(후쿠오카 야타이 거리의 구도 + 주황 천막·한글 네온·플라스틱 의자 + 늦가을 마로니에 낙엽·붉은 벽돌 극장·소극장 포스터).
링크 하나로 입장하면 귀여운 손님 캐릭터가 자동으로 생기고, 빈 의자에 앉으면 **내 사주를 아는 포차 사장님**에게 고민 상담을 받는다.
사장님 스타일은 **프롬프트 한 줄**로 바뀌고(외형·이름·말투·간판·천막 색), 그 변화는 거리의 모든 접속자에게 실시간으로 보인다.
가입 없이 링크로 입장, 말풍선으로 옆자리와 가볍게 대화하는 멀티플레이.

## 1. 실시간 멀티플레이 (Supabase, 무료)
1. https://supabase.com → New project (지역 Seoul/Tokyo)
2. Settings → API: `Project URL` → `VITE_SUPABASE_URL`, `anon public` → `VITE_SUPABASE_ANON_KEY`
3. 테이블 불필요 (Realtime Presence/Broadcast만 사용)

## 2. 배포 (Vercel)
1. 이 폴더를 GitHub 저장소에 업로드 (`.env`, `node_modules`, `dist` 제외)
2. Vercel → Add New → Project → 저장소 Import (Vite 자동 인식)
3. Environment Variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `OPENAI_API_KEY`, `OPENAI_MODEL`=`gpt-6-luna` → Deploy
4. 폰과 PC로 같은 링크를 열어 서로 보이는지 확인 (왼쪽 위 "1번 거리 · N명")
5. OpenAI 대시보드에서 월 사용 한도(예: $5) 설정 권장

> 환경변수를 바꾸면 **Redeploy** 필요. 키가 없으면 오프라인 미리보기로 동작(AI 손님 + 규칙 기반 상담·변신).

## 로컬 실행
```bash
npm install
cp .env.example .env.local
npm run dev      # GPT까지 확인하려면: npx vercel dev
```
`?q=high` / `?q=low` 로 그래픽 품질 강제 (기본: PC 고품질, 모바일 저품질)

## 조작
- PC: WASD/방향키 걷기 · Shift 달리기 · 드래그 시점 · 휠 줌 · 빈 의자 근처에서 E(또는 버튼) 앉기
- 모바일: 왼쪽 아래 조이스틱 · 화면 드래그 시점 · 🪑 앉기 버튼

## 개인정보·안전
- 생년월일은 브라우저 안에서만 계산. 다른 사람에게는 대표 오행 한 글자만 공유. GPT에는 명식 요약만 전달.
- 사주는 재미용으로 안내. 상담사는 의료·투자·법률 결정을 단정하지 않으며, 위기 신호에는 109(자살예방상담전화)를 안내.
- 상담사 스타일은 실존 인물·상표 캐릭터를 흉내 내지 않도록 제한.
